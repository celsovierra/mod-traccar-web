Política de Privacidade

Última atualização: 25 de setembro de 2026

Esta Política de Privacidade descreve como o aplicativo GPScell Manager coleta, usa e protege as informações dos usuários.

1. Informações coletadas

O aplicativo pode coletar:

  • Dados de localização (para rastreamento de veículos)
  • Informações de login (usuário e senha para acesso ao sistema)
  • Token de notificações (para envio de alertas)
  • Imagens capturadas pela câmera (apenas para leitura de códigos QR/códigos de barras)

2. Uso das informações

As informações são utilizadas exclusivamente para:

  • Funcionamento do sistema de rastreamento
  • Autenticação do usuário
  • Envio de notificações e alertas
  • Leitura de identificadores de dispositivos via câmera

3. Compartilhamento

Não compartilhamos dados pessoais com terceiros, exceto quando exigido por lei.

4. Segurança

Adotamos medidas de segurança para proteger os dados dos usuários, incluindo criptografia em trânsito e armazenamento seguro.

5. Permissões do aplicativo

  • Câmera: usada para ler códigos QR e códigos de barras
  • Notificações: para envio de alertas importantes
  • Localização: para exibir a posição dos veículos no mapa

6. Direitos do usuário

O usuário pode solicitar a exclusão de seus dados entrando em contato pelo e-mail: contato@gpscell.site

7. Alterações

Esta política pode ser atualizada periodicamente. Recomendamos revisar esta página regularmente.

8. Contato

Para dúvidas: contato@gpscell.site
